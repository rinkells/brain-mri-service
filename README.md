# Сервіс класифікації МРТ мозку

> **Увага: це навчальний проєкт, а не медичний виріб.**
> Сервіс створено в межах дипломної роботи. Він не проходив клінічних випробувань і
> сертифікації, тому його результати не можна використовувати для діагностики, вибору
> лікування чи будь-яких інших медичних рішень.

FastAPI-сервіс приймає знімок МРТ мозку (JPEG або PNG) і повертає один із чотирьох класів:
`glioma`, `meningioma`, `notumor`, `pituitary`. Разом із класом він повертає ймовірності
всіх класів, попередження про надійність результату і, за бажанням, теплову карту Grad-CAM.

Модель — ResNet18 із torchvision, останній шар якої замінено на шар із чотирма виходами.
Ваги `resnet18_v2_best.pt` навчено окремо; у репозиторії їх немає.

## Запуск

Потрібен Python 3.12. Команди для Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --port 8000
```

У Linux і macOS середовище активується командою `source .venv/bin/activate`.

Перед запуском покладіть файл ваг у `models/resnet18_v2_best.pt` або вкажіть інший шлях
у змінній `MODEL_PATH`. Без ваг сервіс не запуститься і пояснить причину.

Після запуску інтерактивна документація доступна на <http://127.0.0.1:8000/docs>.

**Windows.** PyTorch потребує Microsoft Visual C++ Redistributable. Якщо `import torch`
завершується помилкою `WinError 126`, встановіть
[останню версію цього пакета](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist).

## Налаштування

Сервіс читає змінні середовища; їх також можна записати у файл `.env` у корені проєкту.

| Змінна | Типове значення | Що означає |
|---|---|---|
| `MODEL_PATH` | `models/resnet18_v2_best.pt` | Шлях до файлу ваг |
| `DEVICE` | `cpu` | Пристрій для обчислень: `cpu` або `cuda` |
| `MAX_UPLOAD_MB` | `10` | Найбільший розмір файлу, МБ |
| `MAX_PIXELS` | `16777216` | Найбільша кількість пікселів у знімку (ширина × висота); типове значення відповідає 4096 × 4096 |

Для `DEVICE=cuda` потрібна збірка PyTorch із підтримкою CUDA; як її встановити, описано на
[pytorch.org](https://pytorch.org/get-started/locally/).

## API

### `GET /health`

Повертає стан сервісу, пристрій і класи в порядку виходів моделі:

```json
{"status": "ok", "device": "cpu", "classes": ["glioma", "meningioma", "notumor", "pituitary"]}
```

### `POST /predict`

Знімок передається у полі `file` запиту `multipart/form-data`. Параметр `gradcam=true`
додає до відповіді теплову карту.

```powershell
curl.exe -F "file=@scan.jpg" "http://127.0.0.1:8000/predict"
curl.exe -F "file=@scan.jpg" "http://127.0.0.1:8000/predict?gradcam=true"
```

Приклад відповіді для знімка 640 × 480 без теплової карти:

```json
{
  "predicted_class": "meningioma",
  "probabilities": {
    "glioma": 0.0012,
    "meningioma": 0.9988,
    "notumor": 0.00004,
    "pituitary": 0.0000001
  },
  "image_size": {"width": 640, "height": 480},
  "warnings": [
    {
      "code": "unexpected_image_size",
      "message": "Розмір знімка 640x480, а не 512x512. На знімках іншого розміру модель працює гірше і може пропустити гліому, бо в навчальних даних усі гліоми були 512x512."
    }
  ],
  "gradcam_png_base64": null
}
```

| Поле | Зміст |
|---|---|
| `predicted_class` | Клас із найбільшою ймовірністю |
| `probabilities` | Ймовірності чотирьох класів; у сумі дають 1 |
| `image_size` | Розмір завантаженого знімка в пікселях |
| `warnings` | Список попереджень; порожній, якщо знімок має розмір 512 × 512 |
| `gradcam_png_base64` | Теплова карта у форматі PNG, закодована в base64; `null`, якщо її не просили |

Зберегти теплову карту у файл можна так:

```powershell
$r = curl.exe -s -F "file=@scan.jpg" "http://127.0.0.1:8000/predict?gradcam=true" | ConvertFrom-Json
[IO.File]::WriteAllBytes("$PWD\gradcam.png", [Convert]::FromBase64String($r.gradcam_png_base64))
```

### Помилки

| Код | Коли виникає |
|---|---|
| 400 | Файл порожній, не є зображенням або пошкоджений |
| 413 | Файл більший за `MAX_UPLOAD_MB` або знімок має більше пікселів, ніж `MAX_PIXELS` |
| 415 | Зображення не у форматі JPEG чи PNG (наприклад, GIF, BMP, TIFF, WEBP) |
| 422 | У запиті немає поля `file` або параметр `gradcam` має некоректне значення |

Тіло помилки має вигляд `{"detail": "..."}`. Для коду 422 у `detail` лежить стандартний
для FastAPI список помилок валідації.

Формат файлу визначається за його вмістом, а не за розширенням чи заголовком
`Content-Type`.

## Передобробка

Знімок проходить ті самі кроки, що й під час навчання та перевірки моделі
(`eval_tf2` у навчальному ноутбуці):

1. Перетворення в RGB.
2. `PadToSquare`: знімок розміщується по центру чорного квадрата.
3. `RandomAutocontrast(p=1.0)`.
4. `Resize((224, 224))`.
5. `ToTensor`.
6. `Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])`.

Порядок кроків міняти не можна: автоконтраст працює вже після додавання чорних полів.
Тест `test_transform_is_identical_to_training_notebook` перевіряє, що результат збігається
з кодом із ноутбука точно, до останнього значення.

## Grad-CAM

Теплова карта будується для передбаченого класу за виходом `layer4`, останнього
згорткового блоку ResNet18. Карта накладається на знімок у палітрі `jet`: червоні ділянки
вплинули на рішення моделі найбільше, сині — найменше. Картинка має розмір завантаженого
знімка; якщо його довша сторона перевищує 1024 пікселі, картинка зменшується до 1024.

Grad-CAM показує, на що зважала модель, а не межі пухлини. Карта має роздільність лише
7 × 7 клітинок і розтягується на весь знімок, тому вона груба.

## Тести

```powershell
pip install -r requirements-dev.txt
pytest
```

Тести не потребують справжніх ваг: вони створюють ResNet18 із випадковими вагами в
тимчасовій теці. Один тест додатково перевіряє справжні ваги, якщо файл
`models/resnet18_v2_best.pt` є на місці, а інакше пропускається.

## Docker

```powershell
docker build -t brain-mri-service .
docker run --rm -p 8000:8000 -v "${PWD}\models:/srv/models:ro" brain-mri-service
```

Образ містить PyTorch лише для CPU. Ваги в образ не потрапляють: тека `models`
монтується під час запуску.

## Структура проєкту

```

  config.py         налаштування зі змінних середовища, порядок класів
  preprocessing.py  читання файлу і передобробка знімка
  gradcam.py        Grad-CAM і накладання теплової карти

Dockerfile
requirements.txt, requirements-dev.txt
```

## Обмеження

- **Розмір знімка.** У навчальних даних усі гліоми мали розмір 512 × 512, тому на знімках
  іншого розміру модель працює гірше. На тестовій вибірці з 1600 знімків вона розпізнала
  321 із 324 гліом розміру 512 × 512 (99,1 %) і лише 23 із 76 гліом інших розмірів (30,3 %).
  Для таких знімків сервіс додає попередження `unexpected_image_size`. Розмір тут є лише
  ознакою джерела знімка: якщо просто змінити розмір файлу до 512 × 512, попередження
  зникне, але надійність не зросте.
- **Дані.** Сервіс приймає окремі двовимірні зрізи у форматі JPEG або PNG. DICOM і
  тривимірні дослідження не підтримуються.
- **Чотири класи.** Модель завжди обирає один із чотирьох класів, навіть якщо на
  зображенні не МРТ мозку або є патологія іншого типу.
- **Безпека.** Автентифікації й обмеження частоти запитів немає, тому сервіс не варто
  відкривати в публічну мережу.
